# 🚀 Backend Java — Alura

Repositório com meus exercícios e projetos da carreira **Desenvolvimento Backend Java** da Alura, iniciada em 01/07.

A trilha vai dos fundamentos de programação até arquitetura de sistemas modernos, passando por Java, Spring Boot, APIs seguras, microsserviços, CI/CD e sistemas reativos.

- **Semana 2 — Orientação a Objetos**: Sistema inspirado no Spotify (músicas e podcasts). Herança, polimorfismo e `@Override`.
